# MyGov Podcast – Comparative UX Evaluation

## Project Overview
This project focuses on improving the user experience of the original MyGov Podcast website through a redesigned high-fidelity prototype. 
The evaluation compares the original website with the redesigned version using Think Aloud usability sessions and an 18-parameter UX survey.

## Project Objective
The objective is to identify usability issues in the original MyGov Podcast website and evaluate whether the redesigned prototype makes 
discovering, playing, saving, and resuming podcast episodes easier for users.

## Key Improvements
- Improved homepage organisation and episode discovery.
- Search functionality and topic-based browsing.
- Clearer play buttons and direct episode playback.
- Persistent bottom audio player with playback controls.
- Library for saved episodes, recently played content, and listening progress.

## Final Conclusion Summary
The qualitative evaluation involved five participants who compared the original MyGov Podcast website with the redesigned prototype. 
All five participants preferred the redesigned version. 
The most noticeable improvements were easier episode discovery and direct playback, while the persistent player and Library
also helped make listening more convenient.

However, some areas still need improvement, including long episode titles, clearer episode summaries, 
more readable search results, Library management, and mobile layout. 
The findings suggest that the redesign improved the user experience, but further refinement and testing are needed.
